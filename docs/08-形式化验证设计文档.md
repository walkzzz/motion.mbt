## 2. 证明义务

### 2.1 I1：安全事件抢占

**命题**：`∀ sm : SafetyStateMachine, e : SafetyEvent, sm.current == Executing → ∃ n ≤ 1, transition(sm, Safety(e)).to != Executing`

**证明方法**：
- 运行时断言：`transition` 函数内 `next_state` 的 `Safety(_) => Executing => SafeHold` 分支
- Z3：建模 SafetyStateMachine 为状态机，证明 Safety 事件从 Executing 必到 SafeHold

**代码锚点**：`safety.mbt` `next_state` 函数

### 2.2 I2：FAULT_LOCKED 仅 Reset 解锁

**命题**：`∀ sm, e : StateEvent, sm.current == FaultLocked → (transition(sm, e).to == FaultLocked) ∨ (e == Reset ∧ transition(sm, e).to == Idle)`

**证明方法**：
- 运行时断言：`is_valid_transition` 的 `FaultLocked => match event { Reset => true; _ => false }`
- Z3：建模状态转换表

**代码锚点**：`safety.mbt` `is_valid_transition` 函数

### 2.3 I3：escalation 索引单调递增

**命题**：`∀ sm, transition 序列, sm.escalation_index 单调不减`

**证明方法**：
- 静态分析：`transition` 中 `(_, Recovering) => sm.escalation_index = sm.escalation_index + 1` 仅增不减
- 运行时断言：每次转换后检查 `new_index >= old_index`

**代码锚点**：`safety.mbt` `transition` 函数

### 2.4 I4：SAFE_HOLD 门控关闭

**命题**：`sm.current == SafeHold → gate_closed(sm) == true`

**证明方法**：
- 运行时断言：`gate_closed` 的 `Executing => false; _ => true`
- Z3：建模门控函数

**代码锚点**：`safety.mbt` `gate_closed` 函数

### 2.5 I5：输出门控完整性（新增）

**命题**：`∀ sm, a : String, sm.current != Executing → do_exec(new_gate(sm), a) == false`

**证明方法**：
- Z3：建模 `do_exec` → `is_action_allowed` → `match current { Executing => true; _ => false }`
- 运行时断言：测试 T21 验证

**代码锚点**：`output_gate.mbt` `do_exec` + `safety.mbt` `is_action_allowed`

### 2.6 I6：反馈来源认证（新增）

**命题**：`∀ fb : EnvFeedback, authenticate_feedback(reg, fb) == Ok(fb) → reg.sensors.contains(fb.source)`

**证明方法**：
- 静态分析：`authenticate_feedback` 的 `match reg.sensors.get(feedback.source) { None => Err; Some(_) => Ok }`
- 运行时断言：测试 T18/T19 验证

**代码锚点**：`feedback_auth.mbt` `authenticate_feedback` 函数
