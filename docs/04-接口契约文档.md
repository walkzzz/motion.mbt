## 1. 约定

- 所有签名用 MoonBit 类型表达
- `pub(all)` = 类型公开可构造；`pub` = 函数公开
- 安全前后条件标注 `[sec]`
- 依赖：`moonbitlang/core` + `@walkzzz/gbz185.mbt/*`

## 2. 核心类型接口

### 2.1 safety.mbt

```
pub struct SafetyStateMachine { mut current : SafetyState; mut escalation_index : Int32 }
pub fn new_statemachine() -> SafetyStateMachine
  [post] current == Selftest, escalation_index == 0
pub fn is_action_allowed(sm : SafetyStateMachine, action : String) -> Bool
  [sec I5] 返回 true ⟺ current == Executing
pub fn transition(sm : SafetyStateMachine, event : StateEvent) -> TransitionResult
  [sec I1] Safety 事件抢占式离开 EXECUTING
  [sec I2] FaultLocked 仅 Reset 可离开
  [sec I3] escalation_index 单调递增
pub fn gate_closed(sm : SafetyStateMachine) -> Bool
  [sec I4] 返回 true ⟺ current != Executing
```

### 2.2 bind.mbt

```
pub struct PrimitiveRegistry { primitives : Map[PrimRef, Primitive] }
pub fn new_registry() -> PrimitiveRegistry
pub fn register_primitive(reg : PrimitiveRegistry, p : Primitive) -> Unit
pub enum BindResult { Ok(BoundActionSeq) | Error(Array[Diagnostic]) }
pub fn bind(seq : TargetActionSeq, graph : MappingGraph, reg : PrimitiveRegistry) -> BindResult
  [sec L2] 每 action 经引用解析+冲突+SAC 校验
pub fn check_conflicts(actions : Array[BoundAction], reg : PrimitiveRegistry) -> ConflictReport
pub fn verify_sac_all(actions : Array[BoundAction]) -> SacVerificationReport
```

### 2.3 reaction_engine.mbt

```
pub enum ReactionDecision { Continue | Adjust(ParamMap) | Avoid(AvoidStrategy) | Wait(ConditionExpr, Int64, ReactionAction) | SafeHold | Abort(String) | Replan | FaultLocked(String) }
pub fn react(policies : Array[ReactionPolicy], feedback : EnvFeedback) -> ReactionDecision
  [pre] feedback 已通过 feedback_auth 认证（I6）
  [sec I3] escalation 链深度 ≤ MAX_ESCALATION(5)，耗尽→FaultLocked
```

## 3. 入侵防护层接口

### 3.1 supply.mbt（AS1）

```
pub fn verify_package_signature(pkg : PackageRef, sig : PackageSig) -> Result[Unit, SecurityError]
  [sec AS1] 算法白名单：ed25519/trusted-registry，其他→Err(1701)
pub fn verify_lock_hash(declared : String, actual : String) -> Result[Unit, SecurityError]
  [sec AS1] declared == actual → Ok，否则→Err(1702)
```

### 3.2 nli_guard.mbt（AS2）

```
pub fn guard_nli_result(result : NLI_Result) -> Result[TargetActionSeq, SecurityError]

```

pub fn new_sensor_registry() -> SensorRegistry

pub fn authenticate_feedback(reg : SensorRegistry, feedback : EnvFeedback) -> Result[EnvFeedback, SecurityError]

### 3.4 output_gate.mbt（AS5/I5）

```
pub struct OutputGate { sm : SafetyStateMachine }
pub fn new_gate(sm : SafetyStateMachine) -> OutputGate
pub fn do_exec(gate : OutputGate, action : String) -> Bool

pub fn gate_is_closed(gate : OutputGate) -> Bool
  [sec I4] 非 Executing → true
```

## 4. 错误码契约

| MOT ErrorCategory | code 范围 | MotError 构造子 |
|------------------|-----------|-----------------|
| Syntax | 1000-1099 | Syntax_error |
| Resolve | 1100-1199 | Resolve_error |
| Mapping | 1200-1299 | Mapping_error |
| Conflict | 1300-1399 | Conflict_error |
| Sac | 1400-1499 | Sac_error |
| Reaction | 1500-1599 | Reaction_error |
| Safety | 1600-1699 | Safety_error |
| **Security** | **1700-1799** | **Security_error** |
| Nli | 1800-1899 | Nli_error |

所有 MotError 实现 `@wire.ProtocolError`，统一接入 GB/Z 185 wire 错误契约。

## 5. 退出码契约

| 退出码 | 含义 | 判定 |
|--------|------|------|
| 0 | 成功 | 无 Error 级诊断 |
| 1 | error | 存在 Error 级诊断 |
| 2 | warning | 仅 Warning 级诊断 |
| 3 | internal | 内部错误 |

`exit_code_of(diagnostics) -> Int` 实现此契约。
