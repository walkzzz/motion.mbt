## 2. 清单文件格式

### 2.1 moon.mod（模块清单）

```moonbit
name = "mot/mot"
version = "0.1.0"
description = "MOT (Motion Operation Type) universal action semantics."
import {
  "walkzzz/gbz185.mbt@0.2.2",
}
```

**字段**：name/version/description/import。**无** legacy `readme`/`repository`/`license`/`keywords`/`preferred_target`（这些在 moon.mod.json legacy 格式，现代 moon.mod 用 TOML，但 image.mbt moon.mod 含这些字段——MOT 当前精简版可编译，P1+ 补全）。

### 2.2 moon.pkg（包清单）

```moonbit
import {
  "walkzzz/gbz185.mbt/wire",
  "walkzzz/gbz185.mbt/aip",
  "walkzzz/gbz185.mbt/tooling",
}
```

**关键**：import 必须在 `moon.pkg`，不能在 `.mbt`。根包 moon.pkg 不 import 子包（避免 `unused_package [0029]`）。

### 2.3 moon.work（工作区清单，[P1+]）

```moonbit
members = [
  ".",
  "mot.core",
  "mot.gbz185",
  "mot.bind",
  "mot.reaction",
  "mot.safety",
  "mot.security",
  "mot.diag",
]
```

**模式来源**：image.mbt `moon.work`——11 成员，根 `.` + 子模块。

### 2.4 mot.toml（MOT 项目清单）

```toml
[project]
name = "mot"
version = "0.1.0"

[dependencies]
"@mot/human-bodymap" = "1.0"

[dependencies.lock]
"walkzzz/gbz185.mbt" = "sha256:..."

[security]
verify_package_signature = true
registry_whitelist = ["https://mooncakes.io"]
authenticate_feedback_source = true
output_gate_mandatory = true
prove_invariants = ["I1","I2","I3","I4","I5","I6"]
```

## 3. 工具链

### 3.1 安装

```bash
curl -fsSL https://cli.moonbitlang.cn/install/unix.sh | bash
export PATH="$HOME/.moon/bin:$PATH"
moon version   # 0.1.20261126
```

### 3.2 命令

| 命令 | 用途 | 阶段 |
|------|------|------|
| `moon add <pkg>` | 添加依赖 | 开发 |
| `moon check --deny-warn` | 类型检查（0 error，warning 即 error 门禁） | 验证 |
| `moon check --target wasm-gc/js/wasm` | 多目标检查 | 验证 |
| `moon build` | 构建 | 验证 |
| `moon test` | 运行测试 | 验证 |
| `moon run <example> --target native` | 运行示例 | 开发 |
| `moon info` | 生成 pkg.generated.mbti | 发布 |
| `moon prove <pkg>` | 形式化验证 | [P1+] |
| `moon bench --release --target native` | 性能基准 | [P1+] |
| `moon fmt` | 格式化 | 开发 |
| `moon ide doc <pkg>` | 查 API | 开发 |

### 3.3 四目标编译

| target | 后端 | 状态 |

## 4. P1+ 子模块拆分计划（对齐 image.mbt moon.work）

### 4.1 目标结构

```
mot/
├── moon.work                   # members = [".", "mot.core", ...]
├── moon.mod                    # 根模块（门面）
├── moon.pkg                    # 根包（空）
├── mot.mbt                     # 仅 pub let version + 文档
├── mot.core/                   # L0 基础类型
│   ├── moon.mod                # name = "mot/mot.core"
│   ├── moon.pkg
│   ├── types/moon.pkg + types.mbt
│   ├── bodymap.mbt
│   ├── primitive.mbt
│   ├── mapping.mbt
│   ├── sac.mbt
│   ├── env.mbt
│   ├── reaction.mbt
│   ├── safety.mbt
│   ├── nli.mbt
│   └── targetseq.mbt
├── mot.gbz185/                 # L1 GB/Z 185 集成
│   ├── moon.mod
│   ├── moon.pkg
│   └── gbz185.mbt
├── mot.bind/                   # L2 绑定引擎
├── mot.reaction/               # L2 反应引擎
├── mot.security/               # L2 入侵防护
├── mot.diag/                   # L3 诊断
└── all/                        # 门面包（pub using）
    ├── moon.pkg
    └── all.mbt
```

### 4.2 依赖方向（单向）

```
mot.core (L0, 零依赖 + gbz185/wire)
  ↑
mot.gbz185 (L1, → core + gbz185/aip/tooling)
  ↑
mot.bind (L2, → core + gbz185)
mot.reaction (L2, → core)
mot.safety (L2, → core)
mot.security (L2, → core + safety)
  ↑
mot.diag (L3, → core)
```

- 下层不可依赖上层
- 同层不可互相依赖
- 跨模块用完整路径：`mot/mot.core/types`

### 4.3 门面包 all/

```moonbit
// all/moon.pkg
import {
  "mot/mot.core/types",
  "mot/mot.gbz185",
  "mot/mot.bind",
}

// all/all.mbt
pub using @types {
  type Vec3, type ParamValue, type BodyMap, type Primitive,
  type SacSpec, type EnvFeedback, type ReactionPolicy, type SafetyStateMachine,
  type TargetActionSeq, ...
}
pub using @bind { bind }
pub using @gbz185 { MotError, mot_envelope, mot_tool_descriptor }
```

**模式来源**：image.mbt `all/all.mbt`——`pub using` 再导出，解决"依赖传递、import 不传递"。

### 5.2 安全策略

- 依赖精确版本，禁止 `^`/`~` 范围（AS1）
- mot.toml `[dependencies.lock]` SHA-256 锁定
- `motc install` 强制包签名验证（Ed25519，接入 moon_guard）
- 来源白名单：仅 `https://mooncakes.io`
