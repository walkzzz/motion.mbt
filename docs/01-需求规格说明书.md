## 2. 总体描述

MOT 是 GB/Z 185-2026 在"具身执行"维度的标准实现。形态无关、自然语言驱动、环境反馈闭环、可验证。

**安全立场**：安全优先于功能；安全状态机是唯一权威门控；任何入侵不得绕过输出门控。

---

## 3. 具体需求

### 3.1 功能需求

- **F1 BodyMap**：节点树 + 功能角色 + 语义锚点，不假设关节数/DOF
- **F2 Primitive**：参数模型 + 占用声明 + SAC，分类可扩展
- **F3 Mapping**：有向图，Support/Fallback/Unsupported 三种语义，语义路由器寻优
- **F4 SAC**：类型化声明式契约，内置 trajectory/contact/posture/spatial/count，可插拔验证后端
- **F5 ReactionPolicy**：声明式规则，七种反应动作，escalation 链有界（I3）
- **F6 SafetyStateMachine**：六态，FAULT_LOCKED 仅 Reset 解锁（I2），不变式 I1-I6
- **F7 NLI**：MOT 是 LLM 结构化输出 Schema（Function Calling）
- **F8 绑定引擎四阶段**：引用解析 → 映射展开 → 冲突复检 → SAC 校验

### 3.2 安全需求

- **S1 供应链（AS1）**：mot.toml 依赖锁定哈希 + 包 Ed25519 签名验证 + 精确版本 + 来源白名单
- **S2 NLI 注入防护（AS2）**：NLI 输出必须经绑定四阶段校验 + 危险基元黑名单 + 参数约束
- **S3 AIP 消息安全（AS3）**：复用 GB/Z 185 AIC + AIP 防重放 + 消息类型白名单
- **S4 反馈来源认证（AS4/I6）**：source URN 白名单 + stale_after_ms 强制 + 安全事件抢占
- **S5 输出门控（AS5/I5）**：OutputGate 强制前置 + 非 EXECUTING 力矩归零（I4）
- **S6 类型安全（AS7）**：阶段 1 参数类型校验 + JSON Schema + 禁止 any 逃逸
- **S7 形式化验证（AS8）**：I1-I6 Z3 证明 + quickcheck_statemachine + fuzzing + 变异测试

### 3.3 接口需求
语言无关，退出码 0/1/2/3，安全错误码段 mot.security 1700-1799。
