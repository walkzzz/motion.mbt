## 1. 系统架构（分层全景）

```
应用层：NL 指令 / 动捕 / 场景逻辑 / 多智能体协作
GB/Z 185-2026 协议栈（walkzzz/gbz185.mbt，直接 import）
  AIC · ATR · ACS · ADP · AIP · Tooling · wire(ProtocolError)
MOT 核心语义层
  BodyMap · Primitive · Mapping · SAC · ReactionPolicy · SafetyStateMachine
  NLI · EnvFeedback · TargetActionSeq · BindEngine · ReactionEngine · Diag
入侵防护层（五层纵深防御）
  L1 来源信任 ─ L2 语义校验 ─ L3 运行时认证 ─ L4 输出门控 ─ L5 形式化验证
执行层（Executor 协议，定义接口不提供实现）
环境层（物理/仿真/虚拟）
```

## 2. 模块分解

| # | 模块 | 职责 | 安全层 | 依赖 |
|---|------|------|--------|------|
| 1 | 核心类型 | types/bodymap/primitive/mapping/sac/env/reaction/safety/nli/targetseq | — | moonbitlang/core |
| 2 | 诊断 | 统一错误+退出码 | — | core |
| 3 | 绑定引擎 | 四阶段校验 | L2 | core, diag |
| 4 | 反应引擎 | 反馈→决策循环 | L3 | core |
| 5 | 安全状态机 | 六态+门控 | L4 | core |
| 6 | 入侵防护 | threat/supply/nli_guard/feedback_auth/output_gate | L1-L4 | core, safety |
| 7 | GB/Z 185 集成 | 直接 import gbz185 库 | — | @wire/@aip/@tooling |
| 8 | CLI | motc 入口 | — | 全部 |

## 3. 数据流

```
NL 文本 → NLI guard(AS2) → TargetActionSeq → BindEngine(L2) → BoundActionSeq
  → OutputGate(L4/I5) → Executor → EnvFeedback → feedback_auth(L3/I6)
  → ReactionEngine(L3) → ReactionDecision → SafetyStateMachine(L4)
  → AIP envelope(@aip) → 对端
```

## 4. 关键设计决策

| # | 决策 | 理由 |
|---|------|------|
| D1 | 直接 import gbz185 库，不写桥接层 | gbz185 本身就是 MoonBit 库 |
| D2 | P0 单包 | 消除跨包 import 风险 |
| D3 | 序列用 Array[T] | 默认类型，字面量直接可用 |
| D4 | 安全状态机唯一权威门控 | 具身执行物理后果 |
| D5 | 安全事件抢占绕过反应链 | 防伪造反馈绕过安全 |

## 5. 安全架构（五层纵深防御）

| 层 | 职责 | 覆盖 | 实现 |
|----|------|------|------|
| L1 来源信任 | 包签名验证、依赖锁定 | AS1 | supply.mbt |
| L2 语义校验 | 绑定四阶段+SAC | AS2,AS7 | bind.mbt, nli_guard.mbt |
| L3 运行时认证 | 反馈来源认证、AIP 认证 | AS3,AS4,I6 | feedback_auth.mbt, gbz185.mbt |
| L4 输出门控 | 执行门控 | AS5,I5 | output_gate.mbt, safety.mbt |
| L5 形式化验证 | 不变式证明+测试 | AS8 | safety.mbt 断言, mot_test.mbt |

## 6. 不变式

| 不变式 | 描述 | 证明 |
|--------|------|------|
| I1 | EXECUTING+SafetyEvent→有界步数离开 | Z3+断言 |
| I2 | FAULT_LOCKED 仅 Reset 解锁 | Z3+断言 |
| I3 | escalation 索引单调递增 | 静态分析 |
| I4 | SAFE_HOLD 输出门控关闭 | 断言 |
| I5 | 非 EXECUTING→do_exec false | Z3+断言 |
| I6 | 仅处理已认证来源反馈 | 静态分析+断言 |
