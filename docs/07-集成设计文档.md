## 3. 挂载点详细设计

### 3.1 挂载点 2：AIP 信封（MOT 消息 → AipEnvelope）

MOT 消息类型 → `@aip.MessageKind` 映射：

| MOT 消息 | MessageKind | 用途 |
|----------|-------------|------|
| MotNlRequest | TaskRequest | NL 意图请求 |
| MotActionRequest | TaskRequest | 动作请求 |
| MotBoundAction | Event | 绑定后序列 |
| MotEnvFeedback | Event | 环境反馈 |
| MotReactionDecision | Event | 反应决策 |
| MotSafeState | Event | 安全状态变更 |
| MotActionResult | TaskResult | 动作结果 |

**构造**：`mot_envelope(sender, recipient, seq, kind, payload) -> @aip.AipEnvelope`
- 复用 AIP envelope 的 replay watermarks、session、routing（防重放/会话/路由）
- `envelope_version` 用 `@aip.envelope_version()`

### 3.2 挂载点 3：ToolDescriptor 注册

**构造**：`mot_tool_descriptor(name, description, input_schema, binding) -> @tooling.ToolDescriptor`
- Executor/Sensor 命名空间：`mot.executor.{name}` / `mot.sensor.{name}`
- `@tooling.ToolBinding`：`McpBinding(String)` | `NativeBinding`
- AS6：注册需身份认证（GB/Z 185 AIC）

### 3.3 挂载点 5：ProtocolError trait 实现

```moonbit
pub suberror MotError {
  Syntax_error(String) | Resolve_error(String) | ... | Security_error(String)
}
pub impl @wire.ProtocolError for MotError with fn part(_self) -> String { "gbz185.6" }
pub impl @wire.ProtocolError for MotError with fn code(self) -> String { ... }
pub impl @wire.ProtocolError for MotError with fn message(self) -> String { ... }
```

- `part` → `"gbz185.6"`（AIP 部分）
- `code` → `"MOT-1000"`..`"MOT-1800"`（按类别）
- `message` → 原始消息
- **pub(open) trait 允许跨包实现**（gbz185 wire trait 是 pub(open)）

## 5. 依赖声明（moon.mod）

```moonbit
name = "mot/mot"
version = "0.1.0"
import {
  "walkzzz/gbz185.mbt@0.2.2",
}
```

**moon.pkg**（import 必须在包清单）：
```moonbit
import {
  "walkzzz/gbz185.mbt/wire",
  "walkzzz/gbz185.mbt/aip",
  "walkzzz/gbz185.mbt/tooling",
}
```

**关键**（image.mbt 模式）：import 权限不随依赖传递。MOT 直接 import 的 gbz185 子包必须在 moon.pkg 声明。深层子包（如 `/discovery`、`/identity`、`/capability`）需用时再 add。
