## 1. 术语表

### 1.1 核心术语

| 术语 | 英文 | 定义 |
|------|------|------|
| MOT | Motion Operation Type | 通用动作语义规范，GB/Z 185 具身执行维度的标准实现 |
| BodyMap | Body Semantic Model | 身体语义模型，任意形态身体拓扑的抽象描述 |
| Primitive | Action Primitive | 动作基元，最小语义动作单元 |
| Mapping | Cross-form Mapping | 跨形态映射，形态间动作转换规则 |
| SAC | Semantic Achievement Condition | 语义达成条件，动作正确性判据 |
| ReactionPolicy | Reaction Policy | 反应策略，环境反馈→控制决策的声明式规则 |
| SafetyStateMachine | Safety State Machine | 安全状态机，六态运行时安全管理 |
| NLI | Natural Language Interface | 自然语言接口，NL→MOT 结构化输出 |
| EnvFeedback | Environment Feedback | 环境反馈，传感器数据标准化消息 |
| TargetActionSeq | Target Action Sequence | 目标动作序列，绑定后可执行序列 |
| BoundAction | Bound Action | 绑定动作，经绑定引擎校验后的可执行动作 |
| URN | Uniform Resource Name | `urn:mot:{category}:{name}:{version}` |
| OutputGate | Output Gate | 输出门控，Executor 强制前置门控 |
| MotError | MOT Error | MOT 统一错误类型，实现 ProtocolError trait |
| ProtocolError | Protocol Error | GB/Z 185 全栈统一错误契约 trait |
| AIP | Agent Interaction Protocol | 智能体交互协议（GB/Z 185.6） |
| ToolDescriptor | Tool Descriptor | 工具描述符（GB/Z 185.7） |
| AIC | Agent Identity Certificate | 智能体身份证书（GB/Z 185.1） |
| ACS | Agent Capability Set | 智能体能力集（GB/Z 185.4） |
| ADP | Agent Discovery Protocol | 智能体发现协议（GB/Z 185.5） |

### 1.2 安全术语

| 术语 | 定义 |
|------|------|
| 纵深防御 | 五层防御体系：来源信任/语义校验/运行时认证/输出门控/形式化验证 |
| 攻击面 | AS1-AS8，MOT 的 8 个入侵攻击面 |
| 输出门控 I5 | 非 EXECUTING 状态 do_exec 返回 false 的不变式 |
| 反馈认证 I6 | ReactionEngine 只处理已认证来源反馈的不变式 |
| 安全事件抢占 | 安全事件绕过普通反应链直接进 SafetyStateMachine |
| 供应链安全 AS1 | 包签名验证 + 依赖锁定 + 来源白名单 |
| NLI 注入 AS2 | 防止 prompt injection 诱导危险动作序列 |
| escalation 链 | ReactionPolicy 的递归升级链，有界（≤5） |
| FAULT_LOCKED | 安全状态机锁死态，仅 Reset 解锁 |
| 信任锚 | 包签名验证的公钥来源（P1+ 定义） |
