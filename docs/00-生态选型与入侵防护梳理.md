## 3. 入侵防护架构（核心新增）

### 安全立场
**安全优先于功能；安全状态机是唯一权威门控；任何入侵不得绕过输出门控。**

### 8 个攻击面
AS1 供应链 / AS2 NLI 注入 / AS3 AIP 消息 / AS4 反馈注入 / AS5 安全状态机绕过 / AS6 工具注册 / AS7 类型注入 / AS8 形式化覆盖缺失。

### 5 层纵深防御
| 层 | 职责 | 覆盖 |
|----|------|------|
| L1 来源信任 | 包签名验证、依赖锁定 | AS1 |
| L2 语义校验 | 绑定四阶段 + SAC | AS2,AS7 |
| L3 运行时认证 | 反馈来源认证、AIP 认证 | AS3,AS4,I6 |
| L4 输出门控 | OutputGate 执行门控 | AS5,I5 |
| L5 形式化验证 | Z3 不变式证明 | AS8 |

### 安全不变式（6 条）
I1 安全事件抢占 / I2 FAULT_LOCKED 仅 Reset / I3 escalation 单调 / I4 SAFE_HOLD 门控关闭 / I5 输出门控完整性 / I6 反馈来源认证。
