## 1. 套件定位

本套件是 **MOT（Motion Operation Type）通用动作语义规范** 的完整开发文档集合，面向开发工程师、测试工程师、架构师与形式化验证工程师。

MOT 是 GB/Z 185-2026 在"具身执行"维度的标准实现。本仓库是 MOT 的 **MoonBit 参考实现**，直接复用 `walkzzz/gbz185.mbt` 库。

## 5. 全局约定

1. 类型表达：TypeScript 风格类型描述（MoonBit 参考实现）
2. URN 格式：`urn:mot:{category}:{name}:{version}`
3. 错误码：映射到 GB/Z 185 ProtocolError，1700-1799 为安全段
4. 退出码：0 成功 / 1 错误 / 2 警告 / 3 内部错误
5. 安全状态机六态为唯一权威定义
6. 兼容性：所有已发布 URN 永久稳定
