## 1. 核心约束（不可违反）

1. **禁止目标条件编译** — 不使用 `target == "native"` 等条件分支，四目标（native/wasm-gc/js/wasm）共用代码。
2. **用户直接 import 子模块包** — 根模块仅含 version + 文档，不做 reexport。
3. **gbz185 直接复用** — 不重写 AIP envelope、ProtocolError、ToolDescriptor 等，直接 import `@walkzzz/gbz185.mbt/*`。
4. **安全门控不可绕过** — OutputGate 是 Executor 强制前置。
5. **来源必须认证** — 所有进入 MOT 的数据必须经过来源认证或签名验证。
6. **安全事件抢占** — 安全事件绕过普通反应链，直接进 SafetyStateMachine。

## 3. 安全编码约束

1. **门控前置**：Executor 执行前必须调用 `do_exec(gate, action)`，返回 false 则拒绝。
2. **来源认证**：ReactionEngine 只处理 `authenticate_feedback` 返回 Ok 的反馈。
3. **签名验证**：`motc install` 必须 `verify_package_signature`，失败不写入本地 store。
4. **依赖锁定**：mot.toml 依赖精确版本 + SHA-256 lock，禁止 `^`/`~` 范围。
5. **stale 强制**：EnvFeedback `stale_after_ms` 必须 > 0，超时降级 Stale → SafeHold。
6. **状态机唯一入口**：状态转换必须走 `transition(event)`，无后门。
7. **escalation 有界**：反应链深度 ≤ MAX_ESCALATION(5)，耗尽 → FaultLocked。
