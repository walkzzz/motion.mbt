## 1. 核心类型详细设计

### 1.1 types.mbt

```
pub type URN = String
pub type BodyMapRef = URN
pub type PrimRef = URN
pub type MappingRef = URN
pub type BodyPartRef = String
pub(all) enum ParamValue { PInt(Int32) | PFloat(Double) | PBool(Bool) | PString(String) | PDirection(Vec3) | PEnum(String, Array[String]) | PRange(Double, Double, String) }
pub type ParamMap = Map[String, ParamValue]
#derive(Eq) pub(all) enum ParamType { PIntType | ... | PRangeType }
pub(all) struct Vec3 { x: Double; y: Double; z: Double }
pub(all) struct SpatialDisplacement { translation: Vec3; rotation: Vec3 }
```

**关键**：`ParamType` 必须 `#derive(Eq)`（bind.mbt 用 `==` 比较）。`type` 是关键字，ParamSpec 字段名用 `ptype`。

### 1.2 safety.mbt

六态转换表：Selftest→Idle→Executing↔Recovering→SafeHold→FaultLocked。

**关键函数**：
- `is_action_allowed(sm, action)`：仅 EXECUTING 返回 true（**I5**）
- `gate_closed(sm)`：非 EXECUTING 返回 true（**I4**）
- `transition(sm, event)`：唯一入口，无后门

### 1.3 bind.mbt 四阶段

| 阶段 | 函数 | 关键逻辑 |
|------|------|----------|
| 1 引用解析 | validate_params | 类型匹配+必填校验 |
| 2 映射展开 | find_path_rec | 深度≤5，环检测 |
| 3 冲突复检 | check_conflicts | 独占占用冲突 |
| 4 SAC 校验 | verify_sac_all | 结构完备性 |

orchestration：`bind(seq, graph, reg) -> BindResult` 串联四阶段。

### 1.4 reaction_engine.mbt

`react(policies, feedback) -> ReactionDecision`：匹配策略→walk escalation 链。MAX_ESCALATION=5，链耗尽→FaultLocked（**I3**）。

### 1.5 gbz185.mbt

直接 import 库，不重写。`MotError suberror` 实现 `@wire.ProtocolError`。`mot_envelope()` 构建 `@aip.AipEnvelope`。`mot_tool_descriptor()` 构建 `@tooling.ToolDescriptor`。

## 2. 入侵防护层详细设计

### 2.1 supply.mbt（AS1）
`verify_package_signature`：算法白名单（ed25519/trusted-registry）。`verify_lock_hash`：SHA-256 pinned 校验。

### 2.2 nli_guard.mbt（AS2）
`guard_nli_result`：Uninterpretable→Err(1710) | Ambiguous→Err(1711) | 危险基元→Err(1712) | 安全→Ok。

### 2.3 feedback_auth.mbt（AS4/I6）
`authenticate_feedback`：source 未注册→Err(1730) | stale_after_ms<=0→Err(1731) | 否则 Ok。

### 2.4 output_gate.mbt（AS5/I5）
`do_exec(gate, action)` → `is_action_allowed`（仅 EXECUTING true）。

## 3. 数据流

### 3.1 绑定流程
TargetActionSeq → resolve_all(Stage 1) → check_conflicts(Stage 3) → verify_sac_all(Stage 4) → BindResult::Ok/Error

### 3.2 反应流程
EnvFeedback(已认证 I6) → find_policy → react_rec(walk escalation, depth≤5) → ReactionDecision | FaultLocked

### 3.3 安全流程
StateEvent → transition(唯一入口) → next_state(抢占 I1) → is_valid_transition(I2) → 更新 current+escalation_index(I3) → TransitionResult
